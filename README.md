# 📊 Portfólio de Análise de Dados com Python & Pandas

Este projeto faz parte do meu portfólio de transição para a área de **Dados**. Aqui, utilizo bibliotecas poderosas do ecossistema Python para automatizar a extração, limpeza e análise de grandes volumes de dados, transformando informações brutas em insights estratégicos.

## 🚀 Tecnologias Utilizadas

* **Python**: Linguagem base para automação.
* **Pandas**: Manipulação e tratamento de estruturas de dados de alta performance.
* **NumPy**: Suporte para cálculos matemáticos e arrays multidimensionais.
* **Openpyxl**: Integração para leitura e escrita de arquivos Excel (.xlsx).
