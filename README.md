# 🐍 Análise Exploratória e Comportamento de Clientes com Python & Pandas

Este projeto apresenta um caso prático de Análise Exploratória de Dados (EDA - Exploratory Data Analysis) e inteligência de mercado utilizando Python. O objetivo é extrair estatísticas descritivas, identificar padrões de comportamento de clientes e gerar insights estratégicos para apoiar tomadas de decisão corporativas.

---

## 🎯 O Desafio de Negócio
Em mercados altamente competitivos, compreender o perfil de consumo, a frequência de compra e a sazonalidade dos clientes é vital para a saúde financeira da empresa. O desafio consistiu em processar uma base de dados bruta, identificar distorções estatísticas (outliers), segmentar a carteira de clientes e extrair dores ou oportunidades ocultas que relatórios rígidos tradicionais não conseguem demonstrar.

## 🛠️ Tecnologias e Bibliotecas Aplicadas
* **Python (Linguagem Principal):** Construção de scripts para manipulação e análise de dados.
* **Pandas & NumPy:** Limpeza de dados (Data Cleaning), tratamento de valores ausentes, junção de tabelas, agrupamentos (`groupby`) e transformações matemáticas.
* **Matplotlib & Seaborn:** Desenvolvimento de gráficos estatísticos (como histogramas, boxplots e gráficos de dispersão) para visualização de tendências e distribuições.
* **Jupyter Notebook:** Ambiente utilizado para documentar o código e estruturar o fluxo de *Data Storytelling*.

## 📊 Etapas do Pipeline de Dados (ETL)
1. **Extração e Carga:** Leitura de bases estruturadas contendo o histórico de transações.
2. **Transformação e Higienização:** Tratamento de tipos de dados (strings, datas, floats), eliminação de duplicidades e isolamento de anomalias estatísticas que poderiam enviesar a análise.
3. **Análise Estatística Descritiva:** Extração de médias, medianas, modas, desvio padrão e quartis das variáveis de negócio (Ticket Médio, Volume de Compras, Frequência).
4. **Data Visualization & Insights:** Criação de matrizes de correlação e gráficos sazonais para mapear o comportamento dos clientes.

## 💡 Valor Prático para Business Intelligence e Logística
A habilidade de usar Python para processar grandes volumes de dados brutos capacita o Analista de BI a criar análises preditivas de demandas operacionais. No segmento de *Freight Forwarding*, essa mesma lógica de código é aplicada para prever o comportamento de embarques de importação/exportação, otimizar rotas com base no histórico de tráfego, estimar janelas de *Lead Time* e antecipar gargalos na cadeia de suprimentos.
