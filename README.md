
# 🐍 portfólio: Análise Exploratória de Dados com Python

## 🎯 Objetivo
Explorar dados fictícios de clientes e marketing, aplicando técnicas de EDA (Exploratory Data Analysis) com Pandas, Matplotlib e Seaborn.

## 📂 Estrutura
- **dataset/** → CSV com dados fictícios
- **notebooks/** → notebook com análise exploratória
- **README.md** → documentação do projeto

## 📊 Etapas
1. Carregamento dos dados
2. Estatísticas descritivas
3. Visualizações (histogramas, boxplots, gráficos de barras)
4. Insights de negócio

## 🔎 Insights
- Região Norte lidera em número de compras
- Clientes do gênero feminino apresentam maior gasto médio
- Faixa etária de 30–40 anos concentra maior participação

## 🛠️ Ferramentas
- Python
- Pandas
- Matplotlib
- Seaborn
